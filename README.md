# Визуализатор графа зависимостей пакетов (Ubuntu APT)

## 1. Общее описание
CLI-приложение для анализа транзитивных зависимостей пакетов формата Ubuntu (`apt`), расчёта порядка загрузки и визуализации графа зависимостей в форматах D2, PNG и ASCII-дерева. Реализовано на стандартной библиотеке Python без использования сторонних менеджеров пакетов.

## 2. Функции и настройки
Настройка выполняется через JSON-файл конфигурации:
- `package_name` (`string`) — имя анализируемого пакета.
- `repo_url` (`string`) — URL индекса репозитория (`Packages` / `Packages.gz` / `Packages.xz`) или путь к файлу в тестовом режиме.
- `test_mode` (`boolean`) — включение режима работы с тестовым текстовым репозиторием.
- `package_version` (`string`) — целевая версия анализируемого пакета.
- `output_file` (`string`) — имя выходного PNG-файла с диаграммой D2.
- `ascii_tree` (`boolean`) — вывод дерева зависимостей в консоль в формате ASCII.
- `max_depth` (`integer`) — максимальная глубина рекурсивного BFS-обхода (`>= 1`).
- `filter_substring` (`string`) — подстрока для исключения пакетов из анализа.

# Визуализатор графа зависимостей пакетов (Ubuntu APT)

## 1. Общее описание
CLI-инструмент для анализа и визуализации графа зависимостей пакетов формата Ubuntu (`apt`) без использования готовых менеджеров пакетов и сторонних библиотек для разрешения зависимостей.

## 2. Функции и настройки
Параметры задаются в JSON-файле конфигурации:
- `package_name` (string) — имя анализируемого пакета.
- `repo_url` (string) — URL-адрес репозитория или путь к файлу тестового репозитория.
- `test_mode` (boolean) — флаг режима работы с тестовым репозиторием.
- `package_version` (string) — целевая версия пакета.
- `output_file` (string) — имя выходного PNG-файла с графом.
- `ascii_tree` (boolean) — вывод зависимостей в виде ASCII-дерева.
- `max_depth` (integer) — максимальная глубина анализа (>= 1).
- `filter_substring` (string) — подстрока для исключения пакетов из анализа.
